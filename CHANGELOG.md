# Changelog

All notable changes to the RealmStack dashboard are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project follows
[Semantic Versioning](https://semver.org/).

## 1.0.0

First public release.

- Project and environment workspace with draft, validate, publish, version history and rollback.
- Editors for items, currencies, progression, leaderboards, stats and flags, achievements and quests,
  including a quest canvas with chains, stages and prerequisites.
- Players screen: directory, profile, balances, inventory, progress, stats, achievements, quests,
  cloud saves and moderation, with every game action available to an administrator.
- Dashboard with online-now, peak and daily-active charts.
- AI assistant for proposing configuration, with provider settings and draft-only apply.
- Test client that registers or signs in a demo player the way a game client does.
- Built-in documentation, available before sign-in, with the HTTP reference and a downloadable
  OpenAPI contract.
- Docker Compose demo stack and self-hosting files (static dashboard behind nginx).
